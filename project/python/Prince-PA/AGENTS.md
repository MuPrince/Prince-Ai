# AGENTS.md

> 本文件用于为 AI 编码智能体（如 Codex）提供本项目的工作上下文和协作规则。
> 初始化方式：参照 Codex 的 `/init` 行为生成；请随着项目的创建持续更新本文件。

## 项目概述

- 项目名称：Prince-PA
- 项目位置：`project/python/Prince-PA`（仓库 `Prince-Ai` 下的 Python 项目）
- 项目类型：Python AI Agent 项目
- 项目用途：个人Agent开发学习助理，包含学习任务管理，笔记管理，学习记录等功能。

## 沟通与语言

- 与用户的交流、代码注释、提交信息默认使用简体中文；技术术语可保留英文。
- 回答和文档以简洁、可直接执行为准，避免冗长描述。

## 常用命令

> 以下为常见 Python 项目占位命令，具体命令待项目初始化后确认并更新。

| 用途 | 命令 |
| --- | --- |
| 创建虚拟环境 | `python -m venv .venv` |
| 安装依赖 | `pip install -r requirements.txt` |
| 本地启动服务 | `uvicorn app.main:app --reload` |
| 运行测试 | `pytest` |
| 代码检查 | `ruff check .` 或 `flake8 .` |


## 编码约定

- 使用 Python 3，代码遵循 PEP 8，命名采用 `snake_case`。
- 核心业务代码建议放在 `app/` 或 `src/` 包内，避免脚本堆放在根目录。
- 关键函数和公共接口补充类型标注（type hints）与必要注释。
- 第三方依赖统一记录在 `requirements.txt`（或确认后的依赖管理工具）。
- 敏感信息（API Key、密钥、数据库口令等）只放在 `.env` 或环境变量中，
  不得写入代码、`AGENTS.md` 或提交到版本库。
- 遵循仓库根目录 `.gitignore` 的忽略规则；新增本地运行产物时及时补充忽略项。

## 对 AI 智能体的要求

- 开始任务前先阅读 `AGENTS.md` 与相关文档，确认任务范围。
- 不修改与当前任务无关的文件；删除文件前先确认其确实属于任务范围。
- 修改代码后运行对应的测试/检查命令，验证通过后再报告完成。
- 提交信息使用中文，遵循仓库现有的提交风格，保持提交粒度清晰。
- 遇到不确定的需求时，先说明假设和影响，再继续实现或请求确认。
