# Prince-PA 个人 Agent 开发学习助理 — 产品需求文档（PRD）

## 1. 产品概述

Prince-PA 是一个**本地运行的个人学习助理**，面向正在学习 AI Agent 开发的个人用户，
帮助用户以编程语言为主线管理学习任务、记录学习笔记、沉淀学习总结与学习记录，
并通过聊天的方式让 Agent 参与日常任务维护。

### 产品目标

1. 提供以**编程语言为一级分类**的学习任务管理。
2. 提供网页聊天入口，用自然语言完成学习任务的新增、更新、查询与完成。
3. 提供任务看板，以卡片形式手动管理任务，保证不依赖聊天也能完整使用。
4. 提供 Markdown 笔记编辑能力，笔记以真实 `.md` 文件保存，便于外部工具复用。
5. 在任务完成时自动生成独立的学习总结，并与任务、笔记建立关联。
6. 支持自动/手动记录学习开始时间，沉淀可回顾的学习记录。
7. 建立按用户维度的对话记忆与画像/偏好基础，为后续个性化能力铺路。

### 目标用户与场景

- 目标用户：个人开发者（默认单用户本地使用，不涉及多用户与权限）。
- 典型场景：
  - 用户开始学习“Python / LangChain”，创建对应任务并持续维护。
  - 用户在网页聊天中说“新增一个 Java 的 Spring AI 学习任务”，Agent 自动创建。
  - 用户学习中在笔记编辑器里书写 Markdown 笔记。
  - 用户完成任务后，系统自动生成总结；用户随后确认提炼出的偏好与画像。

## 2. 术语

| 术语 | 说明 |
| --- | --- |
| 语言分类 | 任务的一级分类，如 Python、Java、Go、TypeScript |
| 任务（主题） | 一个学习单元；同一语言下主题唯一，标题即主题名 |
| 笔记 | 用户手写的 Markdown 学习笔记，属于任务 |
| 总结 | Agent 在任务完成时自动生成的 Markdown 文件，与任务/笔记关联 |
| 学习记录 | 记录一次学习开始时间的结构化条目，分为自动与手动 |
| 画像/偏好 | 从笔记、总结与对话中提炼的用户特征与偏好，默认需确认后生效 |

## 3. 产品范围

### 3.1 本期范围（MVP）

- 语言分类管理。
- 学习任务管理：新增、查看、编辑、状态流转（待学习 / 学习中 / 已完成）。
- 任务卡片看板与筛选（语言、状态、关键词）。
- 聊天 Agent：自然语言任务维护、进度查询、标记完成、笔记起草与读取、总结生成。
- Markdown 笔记编辑（编辑区 + 预览区，可拖动调占比）。
- 任务完成时自动生成/更新总结。
- 学习记录：看板“开始学习”自动记录；详情页手动新增。
- 聊天会话持久化与会话内记忆。
- 用户画像/偏好：按用户维度存储，自动/手动提炼，确认后入库（本期不参与行为）。

### 3.2 本期暂不实现

- 多用户、登录鉴权。
- 学习时长统计与计时。
- Agent 代写学习记录、直接修改用户笔记正文。
- 画像/偏好影响 Agent 回复或总结风格。
- `skills/` 插件化机制。
- 移动端适配。

## 4. 功能需求

### 4.1 语言分类

- FR-01：系统支持语言分类作为学习任务的一级分类。
- FR-02：用户可在任务看板/筛选区查看已有语言。
- FR-03：新增任务时可选择已有语言；若语言不存在，允许随任务创建该分类。

### 4.2 学习任务

- FR-10：任务字段包含语言、主题（标题）、描述、状态、创建时间、完成时间。
- FR-11：同一语言下主题唯一，避免笔记/总结文件冲突。
- FR-12：任务状态支持“待学习 / 学习中 / 已完成”。
- FR-13：用户可通过聊天自然语言新增、更新任务，例如“帮我加一个 Python 的
  LangChain 学习任务”。
- FR-14：用户可通过任务看板手动新增、编辑任务，不依赖聊天。
- FR-15：任务支持按语言、状态、关键词筛选，并以卡片形式展示。
- FR-16：任务详情展示完整信息、学习记录与总结入口。

### 4.3 任务卡片看板（主页）

- FR-20：主页为任务看板，整体布局为左侧筛选、中间任务卡片、最右侧聊天窗。
- FR-21：卡片展示任务标题、语言徽标、状态、简介与最近学习概览。
- FR-22：卡片提供操作：详情、开始学习/继续、完成、笔记。
- FR-23：点击“开始学习”将任务置为“学习中”，并自动生成一条学习记录。
- FR-24：点击“完成”将任务置为“已完成”，并触发总结生成。

### 4.4 聊天 Agent

- FR-30：聊天窗固定于任务看板右侧，浏览任务、详情时保持可见。
- FR-31：进入 Markdown 笔记编辑时隐藏聊天窗。
- FR-32：Agent 基于 DeepSeek 大模型与 LangChain 工具调用实现。
- FR-33：Agent 工具能力：新增/更新任务、查询任务并汇报进度、标记完成、
  新增笔记（初始化笔记文件）、读取笔记、起草笔记内容、生成总结、查询语言。
- FR-34：Agent 起草的笔记内容仅在聊天中返回，不直接改写用户已写笔记正文。
- FR-35：Agent 不创建、不代写学习记录。
- FR-36：聊天采用流式响应，并在界面中展示工具调用过程。
- FR-37：聊天会话与消息持久化；同一会话内 Agent 能利用对话记忆连续作答。
- FR-38：新开会话默认不注入其他会话内容。

### 4.5 笔记管理

- FR-40：每个任务对应一份笔记文件：`data/notes/<语言>/<主题>.md`。
- FR-41：笔记正文使用真实 Markdown 文件保存，可由外部 Markdown 工具打开。
- FR-42：笔记编辑器从任务进入，布局为三栏：左侧任务详情（约 1/5 固定宽度）、
  中间编辑区、右侧实时预览区；编辑区与预览区默认各约 2/5。
- FR-43：编辑区与预览区之间支持拖动分隔条调整占比。
- FR-44：笔记内容可保存；首次保存时创建文件。
- FR-45：Agent 可在用户要求时初始化笔记文件或起草内容。

### 4.6 学习总结

- FR-50：同一任务的总结文件与笔记同目录：`data/notes/<语言>/<主题>-总结.md`。
- FR-51：任务完成时系统自动生成/更新总结，生成过程在后台执行，不阻塞看板。
- FR-52：总结生成时读取该任务笔记作为参考内容。
- FR-53：总结文件默认只读展示，并标注由 Agent 生成。
- FR-54：总结生成失败时任务仍为已完成，系统记录失败并提供重试入口。
- FR-55：用户可主动要求 Agent 生成或更新某任务总结。

### 4.7 学习记录

- FR-60：学习记录关联具体任务。
- FR-61：记录类型分为自动（auto）与手动（manual）。
- FR-62：自动记录在用户点击“开始学习”时生成，记录开始时间。
- FR-63：手动记录由用户在任务详情页登记，开始时间可自选。
- FR-64：学习记录不含时长字段，不做计时。
- FR-65：任务卡片与详情页展示该任务的学习记录。

### 4.8 对话记忆与用户画像

- FR-70：系统按用户维度（默认本地单用户 `user_id=local`）组织记忆与画像。
- FR-71：会话记忆保存聊天历史，供当前会话上下文使用。
- FR-72：系统从笔记、总结与 Agent 对话中提炼用户画像与偏好。
- FR-73：自动提炼仅在“任务完成且总结生成成功”后触发一次。
- FR-74：支持用户手动触发画像提炼。
- FR-75：提炼结果先进入待确认（pending）状态，用户逐条确认或忽略后才生效。
- FR-76：画像/偏好维度包括学习语言与重点、学习习惯、总结详略、回复风格。
- FR-77：本期画像/偏好只存储与确认，不改变 Agent 行为。
- FR-78：任务看板左侧提供“用户画像/偏好”入口，展示画像快照与待确认项。

## 5. 页面与交互说明

### 5.1 任务看板（主页）

- 左侧：语言分类、状态、关键词筛选；底部提供“用户画像/偏好”入口。
- 中间：任务卡片网格。
- 右侧：固定聊天窗（仅编辑 Markdown 时隐藏）。

### 5.2 任务详情

- 展示任务完整信息、学习记录时间线、总结入口。
- 支持在详情内手动新增学习记录。
- 提供“打开笔记”入口。

### 5.3 Markdown 笔记编辑

- 进入编辑时隐藏聊天窗。
- 左栏（约 1/5，固定宽度）：任务详情与关联总结入口。
- 中栏：编辑区；右栏：预览区；中间分隔条可拖动调整两栏占比。

### 5.4 用户画像/偏好面板

- 展示当前画像快照、已确认偏好、待确认项。
- 提供“立即提炼”按钮；支持逐条确认/忽略待确认项。

## 6. 非功能需求

- NFR-01：本地运行；默认地址 `http://127.0.0.1:8002`。
- NFR-02：API Key（DeepSeek）由用户自行配置于 `.env`，不写入代码或仓库。
- NFR-03：结构化数据存 SQLite，笔记/总结存真实 Markdown 文件。
- NFR-04：界面文案与注释使用简体中文。
- NFR-05：模型不可用或工具调用失败时，页面给出可读提示，不影响既有数据。
- NFR-06：文件路径安全校验，防止目录穿越与非法文件名。
- NFR-07：`.env`、`data/`、`node_modules`、构建产物等不入库。

## 7. 验收标准

- AC-01：本地启动后，任务看板、聊天窗、笔记编辑、学习记录均可正常使用。
- AC-02：通过聊天新增的任务出现在看板中；通过看板新增的任务可被聊天查询。
- AC-03：点击“开始学习”产生一条自动学习记录；手动登记也可新增记录。
- AC-04：任务完成后自动生成同目录总结文件；无笔记时也能生成并提示。
- AC-05：笔记编辑保存后，外部编辑器可打开对应 `.md` 文件。
- AC-06：任务完成后自动触发一次画像提炼；待确认项可确认/忽略。
- AC-07：聊天历史在页面刷新后仍可查看，当前会话能连续追问。

## 8. 里程碑建议

1. M1：项目骨架与数据层（FastAPI + Vue 工程 + SQLite + 文件目录约定）。
2. M2：任务/语言/学习记录核心流程与任务看板。
3. M3：LangChain Agent 与聊天、SSE 流式输出、工具调用。
4. M4：Markdown 笔记编辑与总结生成。
5. M5：会话记忆与用户画像/偏好提炼确认。
6. M6：联调、测试、文档收尾。

## 9. 后续规划（非本期承诺）

- 画像/偏好参与 Agent 提示词与总结风格。
- 学习时长与统计。
- 基于笔记与总结的检索/问答。
- `skills/` 可插拔能力扩展。
